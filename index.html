Bienvenido a ZaDex

Este espacio nace para reunir y conservar los aportes que he ido compartiendo con el tiempo. Después de que el grupo anterior fue pausado, decidí traer aquí ese contenido para que no se perdiera y pudiera seguir estando disponible. ZADEX es, básicamente, un lugar propio para guardar todo eso que se ha ido acumulando: recomendaciones, recopilaciones, archivos y demás aportes, organizados por categorías para que sea más fácil encontrarlos y consultarlos. La idea es seguir agregando contenido poco a poco y dejar que este espacio crezca con el tiempo.

Cada cierto tiempo ire actualizando el index, ya que hubieron aportes que no pude publicar por una u otra situacion, asi que espero poder crear mi biblioteca personal de aportes :).
